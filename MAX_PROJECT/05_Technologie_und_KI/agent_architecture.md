# 05 — Technologie und KI

## Agentenmodell
MAX soll technisch zu einem persistenten Club-Agenten werden:

Observe -> Plan -> Act -> Measure -> Learn -> Repeat

## Komponenten
1. Club Memory
2. Sponsor Memory
3. Performance Memory
4. Planner
5. Tools / Actions
6. Evaluator
7. Guardrails / Approval Levels

## Rekursives Lernen / Closed Feedback Loop
MAX lernt aus:
- manuellen Textkorrekturen
- Designänderungen
- Freigaben/Ablehnungen
- Views
- Shares
- neuen Follows
- Klicks
- Sponsor-Buchungen
- Sell-through

## Zwei Lernschichten
### Club Brain
Individuelle Tonalität, Designs, relevante Teams, Sponsorregeln.

### Global Brain
Muster über viele Clubs:
- beste Contenttypen
- ideale Timings
- Share-Wahrscheinlichkeit
- Sponsor-Performance
- Preiselastizität

## Distribution
Ein Content-Objekt kann mehrere Outputs erzeugen:
- WhatsApp Channel
- WhatsApp Status
- Instagram Story/Post
- Facebook
- Website

Publisher werden technisch getrennt gehalten, damit APIs später austauschbar sind.
